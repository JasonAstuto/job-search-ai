# Agent Design

## Principles

- Agents are workers, not orchestrators
- Each agent consumes structured input and emits structured output
- Each agent must be policy-constrained
- Each agent action must be auditable

## Proposed agents

- Job ingestion agent
- Job normalization and deduplication agent
- Scoring and recommendation agent
- Resume tailoring agent
- Cover letter and application drafting agent
- Approval review agent
- Playwright preparation agent

## Constraints

- Agents may prepare application artifacts, but never submit autonomously
- Agents must not invent experience, metrics, or accomplishments
- Agents must operate from approved source data only
